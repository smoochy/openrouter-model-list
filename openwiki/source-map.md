## Workflows

| Workflow | File | Schedule | Key Steps |
|----------|------|----------|-----------|
| Daily model lists | `.github/workflows/update-models.yml` | `0 3 * * *` (daily 03:00 UTC) | Checkout → uv sync → generate 3 profiles → commit if changed |
| Weekly Anthropic | `.github/workflows/update-anthropic-models.yml` | `15 3 * * 2` (Tue 03:15 UTC) | Fetch Anthropic API → normalize → commit if changed |
| Bi-weekly OpenWiki | `.github/workflows/openwiki-update.yaml` | `0 5 * * 6` (Sat 05:00 UTC) + gate | Gate: ISO week parity → Checkout → Install openwiki → Fetch ALL sanity_ok models from `models-openwiki.json` → Loop through candidates trying each until one succeeds → Create PR |

### OpenWiki Workflow Details (Corrected)

The workflow **fetches ALL sanity_ok models**, not just the first:
```bash
MODELS=$(curl -sf .../models-openwiki.json \
  | jq -r '[.models[] | select(.sanity_ok) | .id] | join(" ")')
```
Then loops with fallback:
```bash
for model in $OPENWIKI_MODEL_IDS; do
  if OPENWIKI_MODEL_ID="$model" openwiki code --update --print; then
    exit 0
  fi
done
```
Gate job runs on **every trigger** (cron or manual), but manual dispatch always sets `run=true`.

## Operations

| Area | Configuration |
|------|---------------|
| Concurrency | All workflows: `group: update-model-lists`, `cancel-in-progress: false` |
| Secrets | `OPENROUTER_API_KEY`, `ANTHROPIC_API_KEY`, `LANGSMITH_API_KEY` (the daily and weekly model-list workflows no longer use a GitHub App token; they authenticate with the job's built-in `GITHUB_TOKEN` and publish their changes through a pull request) |
| Python env | `uv sync` (pyproject.toml), Python 3.11+ on ubuntu-latest |
| Node env | `actions/setup-node@v7` with Node 24, `npm install -g openwiki` |

## Testing

| Test File | Coverage |
|-----------|----------|
| `tests/test_filters.py` | `parse_param_count`, `is_free`, `supports_structured_output`, `supports_tools`, `filter_candidates` (buffer relaxation, allowlist, hardallowlist, feature requirements) |
| `tests/test_endpoint_stats.py` | `fetch_endpoint_stats` (success, no free endpoints, HTTP error, missing p50) |
| `tests/test_probe.py` | `probe_model`, `record_probe` (trimming), `read_history`, `compute_uptime` (neutral, success rate) |
| `tests/test_scoring.py` | `compute_uptime`, `compute_latency_p50`, `passes_post_probe_filters`, `compute_score` (weights, caps, malus) |
| `tests/test_thresholds.py` | `load_thresholds` (defaults, override, missing keys) |
| `tests/test_openrouter_client.py` | `fetch_models` (success, HTTP error) |
| `tests/test_generate_models.py` | Integration: `generate()` with mocked deps, profile resolution, output schema, probe history, warnings |

## Quick Commands

```bash
# Run single profile
uv run python scripts/generate_models.py --profile mengram
uv run python scripts/generate_models.py --profile yt-summarizer
uv run python scripts/generate_models.py --profile openwiki

# Run all tests
uv run pytest

# Run focused test module
uv run pytest tests/test_filters.py -v
uv run pytest tests/test_scoring.py -v
uv run pytest tests/test_generate_models.py -v
```
